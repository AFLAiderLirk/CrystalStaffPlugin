# Changelog

All notable changes to CrystalStaff will be documented here. This project is currently in active development.

## [1.0.0-SNAPSHOT] — Initial playable prototype

### Added

- Custom 3D Crystal Staff item model supplied through a Minecraft 1.21.4 resource pack.
- `/crystalstaff give` Brigadier command with the `crystalstaff.give` permission.
- Item identification using Persistent Data Containers.
- Crystal Blast triggered by right-clicking the custom staff.
- Purple particle burst, white spark particles, and spell-casting sound.
- Knockback affecting nearby hostile mobs (five-block radius).
- Animated outward-moving purple shockwave ring.
- Five-second ability cooldown with action-bar feedback.

### Planned (unreleased)

- Configurable ability parameters and direct damage.
- Additional spells, staff types, crafting, mana, and localization.

See [Future Updates](README.md#-future-updates) in the README for the full roadmap.
